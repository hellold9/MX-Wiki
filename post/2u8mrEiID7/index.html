LaunchNext：macOS 26 开源启动器

> 重拾桌面自定义的经典体验

项目简介

几天前，苹果又推送了 macOS 26 更新。说实话，我其实并不想升级——担心电脑会变慢。但转念一想，迟早都要升级，拖着也不是办法，于是点了更新。

升级后的第一件事就是找应用，结果我完全迷失了：我的应用都去哪儿了？新版 Launchpad 的界面用起来非常别扭，完全不是我熟悉的工作流。

无奈之下，我去 GitHub 碰碰运气，看看有没有替代方案。结果真的让我找到了一个宝藏项目：@ggkevinnnn 开发的 LaunchNow。

用了一段时间后，我发现这款软件的基础非常扎实。所有核心功能都做得很好：应用布局、文件夹管理、搜索、键盘导航——作者显然是用心在解决问题。但随着使用深入，我觉得还是缺少不少功能，有些地方还可以优化。我再也等不及了，决定亲自下场修改。

当苹果自己的设计选择迫使用户寻找第三方替代品时，这已经足够不便了。用户不应该为了让自己桌面正常工作而经历额外的折腾。于是，LaunchNext 诞生了——一个免费且开源的 macOS 26 Launchpad。

项目地址：https://github.com/RoversX/LaunchNext

LaunchNext 的核心功能

✅ 一键导入系统 Launchpad
直接读取原生 Launchpad SQLite 数据库（/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db），完美复刻你现有的文件夹、应用位置和布局。

✅ 经典 Launchpad 体验
操作方式与你记忆中的原版界面完全一致。

✅ 多语言支持
完整国际化，支持英文、中文、日文、法文、西班牙文、德文、俄文等。

✅ 隐藏图标标签
不需要应用名称时，可启用简洁的极简视图。

✅ 自定义图标尺寸
可根据个人喜好调整图标大小。

✅ 智能文件夹管理
像过去一样创建和整理文件夹。

✅ 即时搜索与键盘导航
无需鼠标点击，快速找到应用。

安装与设置

LaunchNow 采用 GPL 3 许可证，LaunchNext 遵循相同条款，以保持兼容性并尊重原项目的开源精神。

下载与安装

  1. 从 GitHub 下载最新版本
  2. 将 LaunchNext.app 拖入「应用程序」文件夹
  3. 启动应用即可

安全提示

⚠️ 若 macOS 阻止运行，请在终端执行：
sudo xattr -r -d com.apple.quarantine /Applications/LaunchNext.app

原因说明：
作者无力承担苹果开发者证书年费（$99/年），因此 macOS 默认会阻止未签名应用。此命令用于移除隔离标志，仅对你信任的应用执行。

应用会自动检测系统语言并切换对应界面，所有 UI 元素、菜单与提示均已完整本地化。
